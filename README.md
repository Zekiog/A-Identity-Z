# A-Identity-Z

Site for translation, interpretation, and localisation.

The site code is in `A_ID/`. `frontend/` is the React app (public pages and an `/admin` area). `backend/` is a small FastAPI app. Homepage: https://a-identity-z.vercel.app

Interface copy is loaded from locale files for English, Norwegian, Swedish, Danish, German, Turkish, and Arabic.
